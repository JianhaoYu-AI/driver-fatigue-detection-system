## 桌面标签

|编号|名称|语义|
|---:|---|---|
|0|Yawn|打哈欠/张嘴|
|1|close|闭眼|
|2|noYawn|未打哈欠/闭嘴|
|3|open|睁眼|

前三列名称和编号来自 ZIP 的 `data.yaml` 及标签；语义对应项目眼部/嘴部任务。桌面 `best.pt` 的静态类别字典与该顺序一致。

YOLO11 Web 版标签顺序是 `open_eye, closed_eye, open_mouth, closed_mouth`。若希望用这批数据训练 Web 版，需核验标签语义，并把原始编号按 `0→2, 1→1, 2→3, 3→0` 重映射后另存，不能直接按原编号训练。不要覆盖原始标注。
